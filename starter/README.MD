# Project express API

> The goal of this project is to practice how to structure a production express API.

The final project should expose an API for a projects table backed by SQLite (via `better-sqlite3` and the `drizzle-orm` ORM), mainly, a restful CRUD API (i.e., create, read, update, delete).
